## Build System

This project uses **xmake** as the primary build system. The `CMakeLists.txt` is auto-generated by xmake — do not edit it by hand.

```bash
# Configure and build (release)
xmake f -a x64 -m release -p windows -v -y
xmake -v -y

# Configure and build (debug)
xmake f -a x64 -m debug -p windows -v -y
xmake -v -y
```

CI runs the same sequence on `windows-latest` via GitHub Actions (`.github/workflows/build.yml`).

## Project Overview

EconomyBridge is a **static library** for LeviLamina (Minecraft Bedrock Edition server modding) that provides a unified API for reading and writing player currency balances. Consumer mods link against this library and choose an economy backend at runtime.

## Architecture

```
src/
├── econbridge/
│   ├── IEconomy.h              # Abstract interface: get/set/add/reduce/transfer
│   ├── Concepts.h              # C++20 concept EconomyImpl<T>
│   └── detail/
│       ├── LegacyMoneyEconomy.h/.cpp  # Backend: Windows DLL dynamic calls
│       ├── ScoreboardEconomy.h/.cpp   # Backend: Minecraft scoreboard API
│       └── NullEconomy.h/.cpp         # Backend: no-op (disables economy)
└── MemoryOperators.cpp         # Enables LeviLamina's memory operators
```

**Interface** (`econbridge::IEconomy`): Pure virtual methods operating on `mce::UUID`:
- `get(uuid)` → int64_t
- `set(uuid, amount)` → bool
- `add(uuid, amount)` → bool
- `reduce(uuid, amount, allowNegative = false)` → bool — when `allowNegative` is false, returns false if balance would go below zero
- `transfer(from, to, amount, allowNegative = false)` → bool — when `allowNegative` is false, returns false if sender's balance would go below zero

**Concept** (`econbridge::concepts::EconomyImpl<T>`): Every implementation must be `final`, derive from `IEconomy`, and expose `static bool isAvailable()`. Each implementation header includes a `static_assert(concepts::EconomyImpl<...>)` enforcing this.

**Backend selection** happens at runtime by consumers:
- `LegacyMoneyEconomy` — calls into `LegacyMoney.dll` via `GetProcAddress`. Requires the DLL to be loaded in the server process. Resolves player UUID → XUID via `ll::service::PlayerInfo`.
- `ScoreboardEconomy` — wraps Minecraft's `Scoreboard::modifyPlayerScore`. Only works for online players (`uuid2player` returns null for offline). Constructor takes a scoreboard objective name (e.g., `"money"`).
- `NullEconomy` — all methods return success/zero. For disabling the economy.

## Key Compiler/Dependency Details

- **Language**: C++20, MSVC compiler, `/EHa` (async exceptions), `/W4` with selected warnings suppressed
- **Defines**: `NOMINMAX`, `UNICODE`, `LL_PLAT_S` (server platform target)
- **LeviLamina version**: 26.10.0 (pinned in `xmake.lua`)
- **Link-time deps**: LeviLamina, fmt, leveldb, snappy, SymbolProvider
- **Runtime dep**: `LegacyMoney.dll` (optional — only needed for LegacyMoney backend)
- **Build artifact**: static library at `build/windows/x64/release/EconomyBridge.lib`

## Formatting & Linting

- **Style**: `.clang-format` — LLVM base, 4-space indent, 120 column, no tabs, pointer alignment left
- **Static analysis**: `.clang-tidy` enables ~140 checks across bugprone, modernize, performance, readability, and cert categories
- **clangd**: Unused includes are errors (`Strict`); missing includes suppressed; `__FUNCTION__` defined as `"dummy"` for indexing

Run clang-format before committing:
```bash
clang-format -i src/**/*.cpp src/**/*.h
```

## Consumer Integration

Other LeviLamina mods consume this library via xmake:
```lua
add_repositories("iceblcokmc https://github.com/IceBlcokMC/xmake-repo.git")
add_requires("economy_bridge")
```

At runtime, they instantiate a backend:
```cpp
#include "econbridge/detail/LegacyMoneyEconomy.h"
#include "econbridge/detail/ScoreboardEconomy.h"
#include "econbridge/detail/NullEconomy.h"

// LegacyMoney (offline-safe via XUID, requires LegacyMoney.dll)
if (econbridge::detail::LegacyMoneyEconomy::isAvailable()) {
    economy_ = std::make_shared<econbridge::detail::LegacyMoneyEconomy>();
}

// Scoreboard (online players only)
economy_ = std::make_shared<econbridge::detail::ScoreboardEconomy>("money");

// No-op
economy_ = std::make_shared<econbridge::detail::NullEconomy>();
```
